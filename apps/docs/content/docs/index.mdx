Kejasha runs long-term rentals, rent collection and short-stay units from one account. Its
**API is the product**: the web dashboard, the Android app and any integration you build use the
same contract-first HTTP API, documented here in full.

## What the platform guarantees

- **Money never leaves the landlord's own channel.** Rent and booking payments go straight to the
  landlord's or host's Paybill/Till. Kejasha reconciles; it never holds funds.
- **Every organization's data is isolated** by the database itself (row-level security).
- **Money is exact.** Amounts are integer cents everywhere and the books are double-entry:
  balances are derived, never stored.
- **Writes are safe to retry** with an `Idempotency-Key`.
- **The contract is versioned** (`contract-v1.0`): breaking changes fail CI.
